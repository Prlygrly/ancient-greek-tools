Uppercase: Type a capital letter to get the uppercase Greek form. A → Α, W → Ω, Th → Θ, etc.

The h key: h adds rough breathing. It works both directions: after a vowel (ah → ἁ) or before one (ha → ἁ, hippos → ἵππος). When preceded by t, p, or k, it forms a digraph instead: th → θ, ph → φ, kh → χ.

Also available: Single-key shortcuts still work: q → θ, f → φ, c → χ, y → ψ (for when you don’t want to type the digraph).

Stack them! Modifiers combine in any order. ah/ → ἅ (rough + acute). j=| → ῇ (eta + circumflex + iota subscript).

Rough breathing on rho: rh → ῥ (word-initial rho). This doesn’t conflict with digraphs since rh isn’t one.

( still works for rough breathing too, if you prefer: a( and ah do the same thing.
